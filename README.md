## 💡 常見問題 (FAQ)

**Q1：電視安裝後如何清除快取？**  
遙控器在電視主介面**連續雙擊「方向鍵向上 (DPAD_UP)」**即可一秒清理快取緩存，強制同步最新雲端片源。

**Q2：如何安裝到電視機？**  
1. 下載電視版 APK 至隨身碟（U 盤）。  
2. 將隨身碟插入電視或機頂盒 USB 接口。  
3. 在電視的文件管理器中找到 APK 點擊安裝，並允許「未知來源應用」。
